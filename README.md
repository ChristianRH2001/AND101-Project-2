## Summary

**Debugging Tester** is an android app that was riddled with some pretty nasty Kotlin bugs.  With those gone, it's a collection of widgets for a variety of purposes!  It comes ready with six simple features to take a first step into learning about what's possible with Kotlin, as well as what may go wrong when using it.

## Notes

This was an informative first step into the uses Kotlin can have in Android programming, but what was really the most informative was familiarizing myself with how debugging looks in Kotlin. I now have a better idea of what I can expect to be doing when I eventually make mistakes and cause errors. Initially, I needed to use the extra hints to figure out what was wrong with the widgets, but by the fourth button I was able to figure it out on my own.
